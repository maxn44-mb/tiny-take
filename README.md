# Tiny Take

The web pages for Tiny Take, the iPhone app: its [privacy policy](https://maxn44-mb.github.io/tiny-take/privacy.html) and [support](https://maxn44-mb.github.io/tiny-take/support.html).

They are made with the app and published here. The typeface is Allo, by Josh Puckett, under the SIL Open Font License (`fonts/Allo-OFL.txt`).
